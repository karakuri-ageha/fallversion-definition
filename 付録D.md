## 付録D：検証事例データベース

### D-1：使用方法

本データベースはFallversionフレームワークを適用して検証済みの事例を構造化記録するものである。

| 項目         | 内容                                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **目的**     | フレームワークの普遍性を累積的に実証する。新規検証時の参照資料として機能する                                                                                          |
| **更新方針**   | 検証セッションのたびに追記する。既存エントリの判定更新も可とする                                                                                                |
| **記録項目**   | 対象システム・検証日・型分類・接続形態・Main Pipeline現在地・Siphon Line現在地・Normalization Line現在地・並行作動要素の状態・一致度・特記事項                                    |
| **一致度の定義** | Fallversionフレームワークの構造と対象システムの観察結果がどの程度一致するかを百分率で表す主観的指標。100%は完全一致を意味する                                                          |
| **注意事項**   | 本データベースは検証結果の記録であり、対象システムへの価値判断を含まない。第8章で明文化した検証可能性限界が全事例に適用される。なお、現在進行中の事例および複合接続事例については、観察が未完了または個別算出が困難であるため、一致度を未算出とする場合がある |

### D-3：検証済み事例一覧

以下は2026年3月7日の検証セッション（空繰妖華薫 × Claude Sonnet 4.6）における検証結果を、Ver.2.0の構造に基づいて再整理したものである。

※検証時点ではVer.1.1に基づいて診断されたため、Normalization Line・Phantom Immunity・Incubation Period・Acceleration Feedbackの判定は事後的な推定を含む。

|項目|内容|
|---|---|
|**対象システム**|Enron（エネルギー企業）|
